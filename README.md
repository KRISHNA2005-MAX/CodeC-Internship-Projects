# CodeC Technologies Internship – Python Data Analytics Projects

This repository contains two Python Data Analytics projects prepared for internship submission.

## Projects

1. [Market Basket Analysis](01_Market_Basket_Analysis/README.md)
2. [Employee Attrition Analysis](02_Employee_Attrition_Analysis/README.md)

## Technologies Used

- Python 3
- Pandas
- Matplotlib

## Project Structure

- `01_Market_Basket_Analysis/` – Market Basket Analysis project
- `02_Employee_Attrition_Analysis/` – Employee Attrition Analysis project

Each project contains its own README, requirements, source code, dataset and output files.

## How to Run

Open the required project folder and install dependencies:

`pip install -r requirements.txt`

Then run:

`python main.py`

## Dataset Note

The included datasets are sample learning datasets. Employee data is synthetic and does not contain real employee records.
